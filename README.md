# Landing Page

B&Q — це вебпроект, натхненний програмою Bang & Olufsen Recreated Classics. Його мета — передати поєднання вічного дизайну та сучасних технологій через цифрову презентацію колекції Beosystems — обмеженої серії музичних систем, що об’єднують культовий стиль 1972 року з інноваціями сьогодення.

Використані технології:

- HTML5 — структура сторінки

- CSS3 / Tailwind CSS — адаптивний і сучасний дизайн

- JavaScript — взаємодія елементів
